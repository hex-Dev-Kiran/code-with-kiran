HTML fundamentals

Earlier we had learned about paragraph tag,heading tag,link tag,img tag, head tag, body tag, lists, and attributes.

lets go through the difference between elements and tags:

Tags

Labels wrapped in angle brackets that mark the start and end of an element are called tags.

Elements

The complete package consisting of the opening tag, the content inside, and the closing tag.

Empty elements:

empty elements are those who does not need any closing tag.

Inline Elements:

An inline element in HTML is an element that does not start on a new line and only takes up as much width as its content requires

Block Elements:

An HTML block-level element is an element that always starts on a new line and automatically occupies the full width available within its parent

Strong tag

it randers the text in bold to signal importance

em tag

reders the in italic for emphasis

div tag

A generic block-level container used to group elements together for styling.

Comments

You can add notes to your code that browsers will completely ignore. Comments are highly useful for documenting layout choices or code functionality
