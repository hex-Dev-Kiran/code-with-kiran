Link Tag

The link tag defines the relationship between the current document and an external resource.

The link tag is most often used to link to external style sheets or to add a favicon to your website.

Favicon:

A favicon is a small image displayed next to the page title in the browser tab. A favicon is a small image, so it should be a simple image with high contrast.

The link element is an empty element, it contains attributes only.

Rel Attribute:

rel attribute is used to specify the relationship between the link resource and the html Document.

href Attribute:

href attribute is used to specify the location of the URL for the external resource.

Img Tag

Img stands for image.

The HTML img tag is used to embed images directly into a web page. It is a void element (or self-closing tag), meaning it does not have a closing tag, nand cannot contain any text or child elements.

Basic Syntax: At its most basic level, the img tag requires two core attributes to work properly: src and alt.
