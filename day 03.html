Html Boilerplate

Boiler plate is like a readymade template for your website.

A boilerplate includes the basic structure and essential elements every html needed.

Breakdown of the Essential Components

!DOCTYPE html:

Tells the browser the page is written in modern HTML5.

html lang="en":

Declares English as the primary language for accessibility and search engines.

head:

Contains invisible page data like settings, metadata, and external resource links.

meta charset="UTF-8":

Enables correct display of characters, symbols, and diverse text formats.

meta name="viewport" content="...":

Configures the website dimensions to adapt properly to mobile screens.

title:

Sets the text visible on the browser tab bar.

body:

Wraps all visible content like text, links, and images shown to the user.

Some basic elements of HTML

Section

The HTML section tag is a semantic HTML tag used to define a section in the document that generally includes a group of related content.

figure

The figure HTML element represents self-contained content, potentially with an optional caption, which is specified using the figcaption

figcaption

The figcaption tag in HTML is used to provide a caption or description for a figure element.

Orderlist(ol)

an ordered list is created using the ol tag, and each individual item within the list is defined using the li (list item) tag. It is used for squential items such as recipe or top-10 rankings

Unorderlist(ul)

An unordered list in HTML is created using the ul tag. It groups a collection of related items

What are attributes

HTML attributes provide additional information, configuration, or behavioral adjustments to HTML elements. They are some special words and always specified within the opening tag of an element and typically appear as name-value pairs. format: name="value".
